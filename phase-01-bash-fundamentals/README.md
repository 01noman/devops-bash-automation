# Phase 01: Bash Fundamentals

## Overview

This phase covers the basic concepts of
Bash scripting using an Ubuntu Linux VM.

## Topics Covered

- Shell and Bash introduction
- First Bash script
- Shebang
- Variables and assignment
- Command substitution
- User input using read
- Command-line arguments
- Special positional parameters

## Scripts

| File | Description |
|---|---|
| 01-hello.sh | First Bash script |
| 02-variables.sh | Variables and command substitution |
| 03-user-input.sh | Interactive user input |
| 04-command-line-arguments.sh | Script arguments |
| 05-system-info.sh | Linux system information |

## Environment

- OS: Ubuntu Linux
- Shell: GNU Bash
- Version: Check with bash --version

## How to Run

Make the script executable:

```bash
chmod +x 01-hello.sh
